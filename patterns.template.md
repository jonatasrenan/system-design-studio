# Padrões

Decision patterns that repeat across designs, each with the defense already worked out. Sibling of `learnings.md`: that file holds gaps that keep recurring, this one holds decisions already resolved.

Format of each entry:

```
## <decision pattern> (e.g.: SQL vs. KV for the source of truth)
- **Escolha**: what was chosen, in general terms (not tied to one session's specifics).
- **Quando muda**: what about the problem would flip this decision.
- **Defesa em 30s**: the ready articulation, with the nuance that makes the difference.
- **Visto em**: sessions/<slug> (date)
```
